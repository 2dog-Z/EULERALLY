## 项目介绍

EULERALLY 将大学数学知识转化为短时四选一挑战。与其为了提高难度而增加冗长运算，它更重视数学结构识别、合理估算、性质判断与快速准确的数学决策。

例如：

$$
\int_{-3}^{3}x^5\cos x\,dx
$$

无需计算原函数，只要注意到被积函数为奇函数，即可判断积分为 **0**。

**核心目标：** 在开始长计算之前，先发现真正有用的数学结构。

## 为什么选择 EULERALLY？

- **直觉优于冗长计算：** 更强调结构与概念，不靠增大数字制造难度。
- **易于理解，难于精通：** 题目尽量在 1–3 秒内读懂；标准题通常面向 3–15 秒的心算或结构判断。
- **统一的四选一体验：** 规划支持触控与键盘操作。
- **丰富且可迁移的练习：** 不同模板与参数训练同一技能，避免死记固定答案。
- **数学正确性优先：** 明确前提、四个不同选项、恰好一个正确答案。
- **共享的游戏核心：** 纯 TypeScript 数学引擎面向 Web 与 Android 共用。

## 游戏模式

| 模式 | 核心挑战 | MVP 规则 |
| --- | --- | --- |
| **Time Attack（限时挑战）** | **60 秒**内能答对多少题？ | 答对 +1；答错不结束；难度固定；不可暂停或跳过。 |
| **Survival（生存模式）** | **答错一次，挑战结束。** | 无总时限；答对累积连胜；首错结束；难度随连胜提高。 |
| **Zen（禅模式）** | **没有压力，专注数学。** | 不限时、不惩罚失败；自选领域与难度；可跳过、练习相同技能的新题。 |

### Time Attack — 限时挑战

挑战的是整体倒计时，而非每道题的单独时限。主成绩为正确题数；结算还会展示正确率、平均作答时间和最佳连胜。答题反馈计入 60 秒，切换标签页或切到后台也不会暂停倒计时。

### Survival — 生存模式

尽可能延长连续答对纪录。难度按连胜分为 **Warm Up（0–4）**、**Standard（5–14）**、**Advanced（15–29）**、**Expert（30–49）** 和 **Master（50+）**。与 Time Attack 不同，Survival 可以暂停并恢复。

### Zen — 禅模式

没有倒计时，可以按自己的节奏思考。提交后查看正误，再主动进入下一题；**Practice Similar** 旨在生成同技能、不同参数的新题。跳过题目直接切题，既不展示答案，也不计入正确或错误数量。

> **反馈原则：** MVP 仅显示正误，并在答错时显示正确选项；**不自动提供**详细解法、公式推导或提示。

## 数学领域

规划覆盖九个数学方向：

| 领域 | 代表内容 |
| --- | --- |
| **Numerical Sense（数值感）** | 数值估算、对数、Taylor 近似、数量级 |
| **Calculus（微积分）** | 导数、极限、积分对称性、级数 |
| **Vector Calculus（向量微积分）** | 梯度、方向导数、散度、旋度、Jacobian |
| **Linear Algebra（线性代数）** | 行列式、秩、零空间、特征值、正定性 |
| **Abstract Algebra（抽象代数）** | 元素的阶、循环群、同态、环与域 |
| **Number Theory（数论）** | 整除、模运算、欧拉函数、模逆元 |
| **Discrete Mathematics（离散数学）** | 组合计数、图论、递推、逻辑等价 |
| **Mathematical Logic（数学逻辑）** | 命题、反例、缺失假设 |
| **Pattern Recognition（模式识别）** | 结构比较、方法识别、跨领域关联 |

**MVP 优先领域：** 微积分、线性代数、抽象代数和数论。长期题库蓝图为 **35 个子题型、约 290 个模板**；MVP 目标为 **50–60 个模板**，这些是规划目标，不代表目前已上线的题目数量。

### 示例题目

| 领域 | 题目 | 答案 |
| --- | --- | --- |
| 微积分 | $\int_{-2}^{2}x^5e^{x^2}\,dx$ | $0$ |
| 线性代数 | $\det\begin{pmatrix}101&102\\102&103\end{pmatrix}$ | $-1$ |
| 数论 | $3^{100}\bmod 7$ | $4$ |
| 抽象代数 | 加法群 $\mathbb Z_{12}$ 中元素 $3$ 的阶 | $4$ |

游戏中这些题目将以**四选一**形式呈现；表格中的答案仅为展示目的。

## 题目如何生成？

规划中的出题引擎在**本地运行**，支持固定随机种子下的确定性复现，并将数学校验作为必要流程：

```text
知识领域 + 技能 + 难度 + 随机种子
                 ↓
             选择模板
                 ↓
          生成合法参数
                 ↓
          精确计算答案
                 ↓
          生成三个干扰项
                 ↓
       校验前提与答案唯一性
                 ↓
         打乱选项 → 题目缓冲池
```

核心设计约束：

- 题目生成、求值、干扰项生成、校验与缓存全部通过设备端的**纯 TypeScript** 完成。
- 适用场景使用 `BigInt`、专用有理数表示和受约束模板进行精确计算。
- 每题包含**四个数学意义不同的选项**及**唯一正确答案**；正确答案绑定稳定的选项 ID，不依赖打乱后的 A/B/C/D 位置。
- 随机种子及相关算法版本保持一致时，应当复现相同题目与选项位置。
- 通过边界测试、属性测试、独立计算交叉验证来保证正确性；无法可靠证明等价性时弃题重生。
- AI 可以辅助编写模板草稿，但**未经验证的大语言模型实时输出**不作为正式竞技题目来源。

## 平台与数据

| 平台 | 交付方式 | 网络要求 |
| --- | --- | --- |
| **Web** | 在线静态网站 | 首次打开及刷新需要网络；不提供 PWA 或离线启动保证 |
| **Android** | 随包内置资源的 Capacitor APK | 首次安装后即应可断网运行，包括飞行模式 |

两端均在**本地生成数学题目**。个人最佳成绩、会话历史、错题和技能统计计划使用 IndexedDB/Dexie 本地保存。MVP 中 **Web 与 Android 数据不会自动同步**，也不包含服务端、账户系统、在线排行榜、iOS、Electron 或 Python 运行时。

### 本地开发（规划命令）

以下命令来自开发文档，**尚未与实际仓库配置逐项核对**。仓库公开后应将 `<REPOSITORY_URL>` 换成真实克隆地址。

**环境要求：** Node.js、npm；Android 打包另需兼容的 Android Studio、Android SDK 和 Gradle。具体版本下限尚未确定。

```bash
# 仓库公开后克隆
git clone <REPOSITORY_URL>
cd eulerally

npm install
npm run dev
```

```bash
npm run build      # Web 生产构建
npm run test       # Vitest 单元测试
npm run test:e2e   # Playwright 端到端测试
```

**Android 打包（配置完成后）：**

```bash
npm run build
npx cap sync android
npx cap open android
```

然后通过 Android Studio/Gradle 生成调试 APK 或签名 APK。正式 APK 必须从包内 `dist/` 资源启动，不依赖远程 `server.url`。**首次安装飞行模式可玩**属于发布验收要求。

## 技术栈

| 用途 | 规划技术 |
| --- | --- |
| 语言与界面 | TypeScript、React |
| 构建与样式 | Vite、Tailwind CSS、原生 CSS |
| 数学公式 | KaTeX（字体本地打包） |
| 状态管理 | Zustand、纯 TypeScript 状态机 |
| 本地存储 | IndexedDB、Dexie；少量设置使用 localStorage |
| 运行时校验 | Zod |
| Android 打包 | Capacitor、Android Studio / Gradle |
| 精确数学计算 | `BigInt`、自研有理数、受约束算法 |
| 自动化测试 | Vitest、fast-check、Playwright |

`core` 模块设计为不依赖 React、DOM、Capacitor 或具体存储实现。

## 开发路线图

每个阶段都必须可以实际操作和测试，并提交 `STAGE_N_TEST.md` 验收记录。**没有实现与测试证据的 Stage 不标记为完成。**

| Stage | 里程碑 | 可验收交付 |
| --- | --- | --- |
| **0** | 最小功能烟测 | Web 中的固定四选一题目与正误反馈 |
| **1** | 输入与数学显示 | KaTeX、键盘/触屏、防重复提交 |
| **2** | 三模式可玩 | Time Attack、Survival、Zen 完整流程 |
| **3** | 本地数学引擎 | 四个首发领域至少 20 个通过校验的模板 |
| **4** | 训练记录 | 历史、错题、领域筛选、技能统计 |
| **5** | 首个 Android APK | 首次安装后可断网游玩 |
| **6** | Android 游戏式交互 | 触控、生命周期、返回键、暂停恢复 |
| **7** | 跨平台发布 | Web 公开地址与 Android 回归测试 |
| **8** | MVP 发布准备 | 50–60 个模板、性能和发布验证 |

**MVP 之后的潜在方向：** Daily Sprint、用户账户、云同步、在线排行榜、分享，以及 Zen 自适应练习。这些是**未来规划**，不属于 MVP 已承诺功能。
